RUNTIME NOTE
------------
The build container used for packaging does not contain Streamlit, so a full
interactive Streamlit browser-session startup was not executed in this environment.
This is an environment limitation, not a recorded application failure. Release 11.3
retains Streamlit in requirements_ml_agriculture.txt and RUN_APP.bat performs a
startup preflight requiring Streamlit >= 1.48 plus all core/research module imports
on the user's AGROLATTICE environment.

OPTIONAL DEPENDENCY NOTE
------------------------
TabPFN is intentionally optional and was not installed in the build container.
AGROLATTICE 11.3 does not require TabPFN to start. Use
INSTALL_OPTIONAL_RESEARCH_MODELS.bat if that backend is wanted.
