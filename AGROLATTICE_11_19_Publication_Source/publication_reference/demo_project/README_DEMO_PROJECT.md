# AGROLATTICE 11.19 synthetic publication-reference project

This fixed dataset is generated deterministically from seed 1119. It is **synthetic**. It is not a field trial, NASA POWER retrieval, Sentinel observation, sensor stream, or agronomic validation dataset.

It exists so reviewers/readers can reproduce the software workflow, figures, tables, provenance and report packaging without access to private research data.

The weather table contains all 19 canonical AGROLATTICE weather variables solely to exercise the same data contracts as the production application.
