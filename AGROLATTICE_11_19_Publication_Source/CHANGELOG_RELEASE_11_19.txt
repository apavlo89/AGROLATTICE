LIMITATIONS
-----------
• The build container cannot run the complete Streamlit browser app because Streamlit is unavailable offline; genuine UI screenshots must be captured in the target Windows/Anaconda environment.
• The internal publication reference ID is not a DOI.
• The bundled dependency lock documents the reference stack; the exact environment actually used for the paper should also be frozen with FREEZE_PUBLICATION_ENV.bat.
• Synthetic demo metrics are not agronomic validation evidence.
