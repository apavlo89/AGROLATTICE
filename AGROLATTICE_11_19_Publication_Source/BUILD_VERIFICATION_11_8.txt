PERFORMANCE SAFEGUARDS
----------------------
- Fields & Operations Overview uses lightweight SQL summaries and small persisted
  metadata reads.
- Portfolio Attention uses one aggregate SQL query instead of multiple count
  queries per field.
- Folium spatial maps are built only when a spatial workflow is selected.
- Overview does not automatically call NASA POWER.
- Overview does not automatically query Sentinel/STAC or process raster imagery.
- Overview does not run the Persistent Twin, crop models, ML training or optimizers.
- Release 11.6 process-local climate/service caching remains intact.

SCIENTIFIC / DATA-INTEGRITY SAFEGUARDS
--------------------------------------
- Field geometry remains authoritative.
- Planned operations and actual operations are explicitly separated.
- Recommendations are linked but are not silently converted to applied operations.
- Custom operation polygons must be contained by the field geometry.
- Alert persistence/cooldown is explicit rule logic, not pest/disease diagnosis.
- Observation protocols record quantitative values with provenance; they do not
  invent significance or biological interpretation.
- Sensor QC remains broad physical/data-quality screening, not calibration proof.
- K-means outputs are labelled exploratory point clusters unless further spatial
  modelling/validation supports management-zone interpretation.
- Mechanistic Maize Twin code is unchanged.
