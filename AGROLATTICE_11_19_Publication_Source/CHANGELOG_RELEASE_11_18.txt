INTEGRATION AUDIT
-----------------
The audit checks:
• SQLite integrity and local foreign keys;
• Trial → authoritative Field references;
• whether a Trial's saved source-field geometry hash became stale after field-boundary editing;
• Persistent Twin → Field/Trial references;
• Research Evidence Field/Trial/Experimental Unit references where those context IDs are present;
• explicit report Field/Trial scope references.

These checks are integration/reproducibility safeguards, not scientific validation.

PERFORMANCE

DATABASES / MIGRATION

PROTECTED SCIENTIFIC ARTIFACTS

LIMITATIONS
-----------
• Full interactive browser testing still requires the user's target Streamlit/Windows environment.
• Session timings include whatever explicit work the researcher triggered during that render; they are diagnostics, not standardized benchmarks.
• Cross-database reference checks cannot establish agronomic, statistical or causal validity.
