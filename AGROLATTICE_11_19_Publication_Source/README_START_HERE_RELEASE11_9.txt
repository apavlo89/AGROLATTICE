AGROLATTICE 11.9 — START HERE
============================

Release title
-------------
Persistent Twin Command Centre & Mechanistic Integration

What is new
-----------
The AgroLattice Twin is now organised around one persistent Active Twin instead
of five loosely connected analytical pages. For a maize synchrony trial, the
Persistent Twin now uses the existing Mechanistic Maize Twin physiology as its
preferred flowering engine and combines it with the persistent field, weather,
root-zone, EO, sensor, experiment, observation and evidence layers.

Main Twin views
---------------
Overview
  Twin Pulse, state chain, priority measurement prompts and quick navigation.

Spatial Twin
  Field/trial/experimental-unit map with optional sensors, scouting, operations
  and treatment-unit analytical overlays.

Development & water
  Parent physiology provenance, mechanistic flowering timing, leaf trajectories,
  root-zone water and EO trajectories.

Timeline
  Time-travel reconstruction, management/observation/phenology timeline and saved
  Twin checkpoints.

Scenarios
  Mechanistic male-sowing strategy exploration plus clearly separated exploratory
  environmental/management scenarios.

Measurements & copilot
  Prioritised next measurements, field-task creation, flowering observation
  protocol integration and Recommendation → Action → Outcome handoff.

Evidence & validation
  Data/provenance evidence, calibration audit, model disagreement, observed
  outcomes, registered predictions/recommendations and export package.

Setup
  Data sources, crop model/calibration, readiness and advanced/export controls.

Important scientific note
-------------------------
The maize timing equations are the disclosed Laurent et al. (2025) concepts
already implemented in AGROLATTICE (DOI 10.1002/csc2.21453). Publication priors
for tln, coblf and ebR1 are assumptions, not measurements of your local lines.
The original proprietary dataset and C++ Bayesian sampler are unavailable, so
AGROLATTICE must not be described as an exact reproduction of the publication.

Starting the app
----------------
Use RUN_APP.bat from the AGROLATTICE folder in the same Windows/Anaconda setup
used for previous releases. The preflight verifies the 11.9 Twin module and DB
schema before Streamlit launches.
