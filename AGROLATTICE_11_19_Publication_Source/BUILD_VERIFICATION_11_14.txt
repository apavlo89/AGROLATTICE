IMPLEMENTATION SCOPE
--------------------
11.14 rebuilds Models & Evidence as AGROLATTICE's scientific-governance workspace.
Major implemented capabilities include:
- true lazy Model Evidence Command Centre;
- registry model filtering and coherent Model Detail pages;
- persistent training-run records for successful, inferior and failed candidates;

- empirical interval-coverage and probability-reliability diagnostics;

- model-ranking stability across folds/repeated holdouts;
- applicability/OOD inspection and outcome-linked model-health/drift monitoring;
- predictive explainability with artifact-integrity checks;
- registry-native compatible-model comparison, disagreement and paired bootstrap delta-RMSE uncertainty;
- external benchmark execution from explicit researcher-supplied local resources with reproduction-status provenance;
- prediction -> measured outcome linking with spatial/season context and chronology visibility;
- Evidence Graph and reproducibility ZIP export;
- dataset snapshot manifests and source-method/paper implementation relationship display;
- retention of k=2..20 PCA/K-means climate exploration introduced in 11.13.

SCIENTIFIC-GOVERNANCE GUARDS VERIFIED
-------------------------------------
- New model registrations cannot silently start at a promoted status.
- Existing model upserts cannot silently mutate evidence status.
- Model promotion requires written rationale.
- Internal validation excludes diagnostic-only evidence and requires documented split/leakage safeguards.
- External/operational promotion does not treat every generic leave-one-group result as external validation.
- OOD/model disagreement is not labelled calibrated uncertainty.
- Equal-weight OOF ensembles are diagnostic only; learned stacking weights are not promoted without leakage-safe meta-training.
- Predictive feature importance is explicitly not causal inference.
- Benchmark resources are not silently downloaded.
- Prediction/outcome matching is auditable and chronology is surfaced.

PERFORMANCE
-----------
The top-level Models & Evidence workspace uses lazy navigation. Inactive pages do not execute.
Artifact loading, permutation importance, partial dependence, validation calculations, benchmark execution and legacy advanced tools require explicit researcher actions.
Large registry tables are requested with bounded limits and scoped filters where applicable.

KNOWN LIMITATIONS / DELIBERATE SAFEGUARDS
-----------------------------------------
1. A full interactive Streamlit browser session could not be run in this packaging environment because Streamlit is not installed here. RUN_APP.bat performs the target-environment preflight on Windows/Anaconda.
2. Official CropNet/YieldSAT/WorldCereal dataset retrieval is not automatically initiated. Dataset sizes, licences and upstream schemas must be reviewed before retrieval; 11.14 executes benchmark evidence from explicit local resources.
3. Generic learned stacking/ensemble weights are not automatically trained/promoted because safe stacking requires nested or out-of-fold meta-training separated from final evaluation.
4. Generic SHAP remains model/backend dependent. Permutation importance and PDP provide broadly compatible predictive interpretation; the existing advanced pest workflow retains SHAP support.
5. Automated prediction-outcome matching uses target, spatial context and season where available. It must be reviewed by the researcher and does not establish causal treatment effects.
6. Drift diagnostics compare linked errors over time but do not identify the cause of performance degradation.
7. Dataset snapshot manifests freeze provenance/transformation state. Raw data bytes are only immutable when a stable local file/hash is also recorded.
8. Evidence status remains a scientific-governance judgement. An auditable override is possible but never creates missing empirical evidence.
