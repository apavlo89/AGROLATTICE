AGROLATTICE 11.12 — BUILD VERIFICATION
======================================
Release: Navigation Reliability & Interaction Fix
Baseline: AGROLATTICE 11.11 — Crop Decision Command Centre & Agronomic Planning

BUG REPRODUCTION / ROOT CAUSE
-----------------------------
User report: the Priority decisions & evidence gaps buttons on Crop Decisions →
Overview appeared to do nothing.

Inspection of the actual 11.11 source found two navigation states:
  crop_decision_command_view        (logical mirror)
  crop_decision_command_view_radio  (Streamlit widget-owned state)

The buttons changed only the logical mirror. On rerun the keyed radio restored
its persisted Overview value, overriding the requested destination. Mutating the
radio key from a button after the radio had already been instantiated would also
be unsafe in Streamlit.

FIX IMPLEMENTED
---------------
Added navigation_state.py 1.0.0 with a two-phase queued route mechanism:
  button -> non-widget request key -> rerun -> consume before widget creation ->
  synchronize widget + mirror state -> render requested destination.

Applied to:
  1. Crop Decision priority-action buttons.
  2. Persistent Twin programmatic workspace shortcuts (same latent pattern).
  3. Climate & EO Update field EO -> Earth Observation shortcut (same latent
     widget-state pattern).

Crop Decision target areas regression-tested:
  PASS Crop & planting
  PASS Water & irrigation
  PASS Nutrition
  PASS Pest & crop health
  PASS Yield & economics
  PASS Crop models
  PASS Recommendations & outcomes

The destination also receives a one-time contextual note identifying the
priority action that routed the user there.
