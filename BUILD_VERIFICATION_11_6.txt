PURPOSE
-------
This release addresses ordinary Streamlit navigation/rerun latency and integrates
AGROLATTICE's new brand logo. It does not change scientific algorithms or crop
model parameters.

PERFORMANCE AUDIT FINDING
-------------------------
The bundled Mexico climate table is 607,497,870 bytes (~579.4 MiB) with
8,792,484 rows. Release 11.5 performed a redundant full active-country status
CSV read during top-level script execution even after climate data had already
been loaded. A build-container probe of that Release-11.5-style status read took
~9.43 seconds and reached ~1.51 GB maximum resident memory. The exact timing is
environment-specific; the important verified code change is that this redundant
status-read call is absent from normal 11.6 top-level navigation execution.

11.6 PERFORMANCE CHANGES VERIFIED
---------------------------------
- Active-country prepared climate runtime uses a process-local Streamlit resource
  cache rather than repeatedly serialising/copying the multi-million-row table.
- Cache invalidation uses source path + size + nanosecond mtime for the cities
  catalogue and active climate file, avoiding a full-file hash on each rerun.
- Dataset status is calculated from the already prepared climate DataFrame.
- Latitude/longitude attachment uses the small location lookup; when every
  climate location matches, the merged analysis frame aliases the climate frame
  instead of duplicating the full climate columns.
- Field Operations, Pollination Lab, Persistent Twin, Research Evidence,
  ProjectStore and StudyStore service objects are cached between reruns while
  SQLite connections remain short-lived per operation.
- Unchanged country settings are no longer rewritten to disk on every rerun.
- System Diagnostics includes runtime-cache metrics and explicit reload controls.
- The new horizontal AGROLATTICE logo and square icon are bundled and wired to
  the app branding path, with a safe fallback if the installed Streamlit lacks
  the logo API.

LIMITATIONS / HONEST TEST BOUNDARY
----------------------------------
- The first use of a very large active-country CSV in a fresh Python process still
  requires one genuine parse/preparation pass. 11.6 primarily removes repeated
  work on subsequent Streamlit reruns/navigation.
- Satellite rendering, very large interactive maps, external API requests and
  model training retain their inherent task latency.
- Streamlit is not installed in the packaging container, therefore a full
  interactive browser-navigation timing test was not performed or claimed.
  RUN_APP.bat performs dependency/module/version preflight on the user's target
  Windows/Anaconda installation.
