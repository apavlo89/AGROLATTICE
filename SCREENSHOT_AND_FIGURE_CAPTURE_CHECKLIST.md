# Publication screenshot and figure capture checklist

AGROLATTICE 11.19 bundles publication-ready architecture/workflow/demo figures. A genuine Streamlit UI screenshot must be captured from the target Windows/Anaconda environment because the build container cannot run the complete Streamlit browser application.

Recommended manuscript screenshots from the frozen 11.19 installation:

1. Home Research Command Centre showing the persistent research context.
2. Fields & Operations spatial layout with authoritative field geometry.
3. Persistent Twin overview showing state/evidence chain without exposing private identifiers.
4. Experiment Command Centre spatial trial layout coloured by one declared factor.
5. Models & Evidence overview showing validation/applicability rather than a cherry-picked score.
6. Reports & Publication showing frozen evidence/reproducibility status.

Before capture:

- use a synthetic/public-safe project or redact private field/genotype identifiers;
- show the 11.19 release header/reference identifier where practical;
- avoid screenshots containing API keys, file-system usernames, personal contact data or precise coordinates that should remain private;
- record the screen/page, date and evidence snapshot used;
- do not label synthetic demo content as field data.

Bundled non-UI figures are under `publication_reference/figures/` in both PNG and SVG and can be used immediately.
