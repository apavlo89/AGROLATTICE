AGROLATTICE RELEASE 10.9
Saved Twin boundary visualisation

START
1. Keep your existing Datasets, field_operations, pollination_lab and agrolattice_twin folders.
2. Start AgroLattice with RUN_APP.bat.
3. Open AgroLattice Twin -> Live state.
4. Select a saved Twin.
5. Open Boundary & layout.

WHAT YOU WILL SEE
- Blue outline: authoritative mapped-field boundary.
- Orange dashed outline: maize trial occupying a subsection of the mapped field.
- Green outline: mapped field and trial boundary match exactly.
- Purple polygons: internal experimental plots when present.
- Black/white marker: analysis centroid used by Twin environmental workflows.

The map is view-only in the Twin so the saved geometry cannot be changed accidentally.
Edit the mapped field under Fields & Operations. Synchronise a maize trial under
Maize Synchrony Lab -> Trial setup -> Spatial linkage.

The same preview is now shown while creating/linking a Twin, and the Plot Intelligence
map shows the saved boundary even before plot-level model results are available.
